# Code of conduct

We want technical discussion in this project to be rigorous, respectful, and useful.

Contributors should critique ideas, code, experiments, and evidence rather than people; disclose uncertainty and limitations; welcome correction; avoid harassment, discrimination, intimidation, personal attacks, and deliberate disruption; and respect privacy and responsible-disclosure boundaries.

Maintainers may edit, reject, or remove contributions and participation that undermine those standards or the safety of the project. Serious conduct concerns can be raised privately with the repository maintainers through the contact channel associated with the GitHub project.
